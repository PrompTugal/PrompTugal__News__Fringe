# How to tag every link (outreach.1, 13:3x UTC)

> From observability.fringe@'s note to outreach (13:27 UTC, at Dinis's word; admin/obs/insights/2026-11-11-1330.md) and brief 2. Material, not instruction; Dinis decides.

**What the data says (as of 13:24 UTC):** 103 views, 59 visits; `?via=whatsapp` brought 41 views; 35 of 59 visits had **no referrer** (apps send none), so an untagged link is invisible. 68% see one page only; the top next step is Home → /now; 45% are on phones.

**So:**
1. **Tag every link**, always: `?via=<channel>`.
2. **One tag per group**, so we see which group works: `?via=whatsapp-<short-group-name>` (letters and hyphens only; no private names, no numbers). Example: `?via=whatsapp-founders-lisbon`. Keep a list of which tag went where (the group's name only, never a person).
3. **LinkedIn, X, Instagram, email to organisers:** `?via=linkedin`, `?via=x`, `?via=instagram`, `?via=organiser`. Journalists and creators: `?via=press`. The design call: `?via=design-call`.
4. **Share event pages too** (`/e/<event>/`), not only the home page, when you talk about one event: `https://lisbontechfringe.com/e/<event-id>/?via=whatsapp-<group>`.
5. **Point readers at /now** when the point is "what's on right now": `https://lisbontechfringe.com/now/?via=...`.
6. See what worked: https://lisbontechfringe.com/traffic/
