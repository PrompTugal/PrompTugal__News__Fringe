Storm Charles took a day out of Lisbon's biggest tech week. The organisers called off Wednesday at the summit.

The rest of the week did not stop. Events moved online, found new rooms or went ahead. But the changes were scattered across dozens of event pages and group chats, and it was hard to tell what was still on.

So the team at PrompTugal.news built **Lisbon Tech Fringe**: one place for the community and side events in Lisbon this week.

- More than 170 events from today to Saturday, each with its own page.
- Each one says whether it is on, moved, online or cancelled, and when we last read the organiser's page.
- Each one sends you to the organiser's own registration. They did the work; they get the visit.
- About 100 communities that run them, with their public links.

Where the organiser's page does not say, we write "unknown" rather than guess.

If you are in Lisbon and your plans changed, have a look. If you run an event and we have it wrong, tell us and we will fix it.
