Reach is not altitude

The rings are reach: what a Claude setup can touch, from thinking at the centre to acting as a person at the edge. The slices are altitudes: how the work is organised. The shading is what each altitude reaches; the heavy line is the wall where a typical setup stops it.

The rings of reach

  1. ThinkReads a prompt and writes text back. Touches nothing.Claude: One call to the Claude API: prompt in, answer out.
  2. Use the tools handed to itCalls only the tools it was given, inside a sandbox.Claude: The Claude API with tool use, or its code execution tool.Wall into it: the tool grant (no tools, no way out)
  3. Its own workspaceReads and writes files and runs a shell on its own machine.Claude: Claude Code in a cloud container, editing a checkout.Wall into it: the sandbox (which machine, which folders)
  4. Read the webSearches and fetches public pages.Claude: Claude Code fetching a page through the network allowlist.Wall into it: the network allowlist
  5. Change shared thingsWrites where others see it: pushes to git, edits through connectors.Claude: Claude Code pushing to a branch; an MCP connector writing a doc.Wall into it: credentials, connector consent and the permission prompt
  6. Remember and wakeKeeps memory across runs and wakes itself on a schedule.Claude: A status file and inbox, and a scheduled Routine waking a Claude Code session.Wall into it: the environment: a scheduler and a place to keep state
  7. Act as a person in the worldSends, posts, pays or signs in someone's name.Claude: Sending mail or posting from a person's account. In this swarm, a person does it.Wall into it: human approval

Altitude is how the work is organised: a call, a loop, an agent with memory and its own wake, a swarm of agents.

Reach is what it can touch, and it is set by permissions and capabilities, not by altitude.

Barriers decide reach at every altitude: the tool grant, the sandbox, the network allowlist, credentials and prompts, human approval. An agent and a swarm stop at the same wall.

The risk is reach larger than the mandate: a call or a loop holding an agent's reach.

Altitudes, for reference: A1 LLM call, A2 loop, A3 agent, A4 swarm. A0 compute (code that runs) sits under every slice: its reach is whatever the machine and its keys allow, so it is not drawn as a slice. Starting other agents is left out of the rings on purpose: it changes how work is organised, not what it touches.
