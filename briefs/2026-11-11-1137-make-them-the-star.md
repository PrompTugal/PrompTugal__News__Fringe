# Brief 3: make them the star

**The example.** Someone posted in a public-interest WhatsApp group: "Portugal Tech Week palace went fully online today! all events tagged as PTW palace have their luma updated and you can now see sessions online https://events.portugaltechweek.com/". With it was the day's online agenda (eleven sessions, 11:00 to 22:00). The sender is a private person: **never name or link them, and never copy their number**. The public fact and its public source are what we use. The lead's researcher sub-agent is checking each session at its public page now (11:37 UTC).

## In Dinis's words

> "First of all, we should be mapping this up. B is the kind of message I want to post on these kind of WhatsApp messages ... we need to create a page for this event on us. So every single event that exists, we need to have the page on our site, and we should be linking and making that event better."

> "We should be capturing everything, we should be mapping everything, and again, we should have a schedule, everything that's happening, including live feeds."

> "This is about making them the star. This is not about taking traffic from them ... it's about feeding them and acknowledging them and really making them better. But ... we should be consuming what they have, and again, we can run this thing on a loop."

> "We should always make the offer to say, hey, work with us, we'll give you access to the agents, we can coordinate, they can join our team. So we need to also reach out to every single one of these people, because remember that joining us is just one session on the other side ... we can have a report for them. Let's really map it all happening."
